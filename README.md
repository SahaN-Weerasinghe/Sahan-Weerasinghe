## 🚀 About Me

- 💼 Founder & Lead Developer at **Noventra Web Solutions (Pvt) Ltd**, a Sri Lanka–based engineering studio
- 🧩 I design and ship full-stack web platforms and native Android apps end-to-end — backend, database, API, and UI/UX
- 📱 On Android, I build with **Clean Architecture**, **MVVM**, and 100% **Jetpack Compose**
